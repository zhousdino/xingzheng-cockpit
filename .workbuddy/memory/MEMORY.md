## 批量导入方案（v1.15.0 起）
- 车辆 / 签证看板各内联一套**自包含批量导入模块**（模板下载 + CSV 解析校验预览 + 导出核对文件），无需后端、不直连资料库。
- 真实写入由**管理员后台**执行：用 `lib_import.py`（CSV→资料库，batch_add 追加，schema 下拉校验 + 日期/数字归一 + ≤100 分批）→ 写入后 hourly 自动化同步进看板。
- 模板 CSV 列名必须与资料库字段**一字不差**（下拉项见下，来自 schema）：
  - 车辆(21)：车牌/车型/车辆类别/燃料类型/车架号/所有情况/使用单位/租赁起始日/租赁到期日/保险/保险到期/年检到期/通行证/通行证到期/状态/驾驶员/当前位置/上报时间/当前里程/下次保养日期/备注。单选：车辆类别=公务轿车/SUV越野/皮卡/中巴客车/货车；燃料类型=汽油/柴油/新能源；所有情况=自购/租赁；状态=正常/保养/维修/停用。
  - 签证(8)：姓名/护照类型/护照有效期至/签证类型/签证签发日期/签证到期日/Iqama办理状态/最近一次飞签时间。单选：护照类型=普通护照/公务护照/外交护照；签证类型=工作签证/商务签证/访问签证/旅游签证/其他；Iqama办理状态=未开始/办理中/已完成/已注销。

- 状态：已告知用户，选「先反馈 bug + 前端照做」。修复前 dashboard 不显示真实录入数据；lib_import.py 写入本身有效（记录存在），修复后即可同步显示。

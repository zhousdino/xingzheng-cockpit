## 本地桥接服务 v1.5.0（约 15:45）——解决"实时更新 WPS+腾讯表"
- 用户诉求："我需要实时更新 WPS 和腾讯的表格"。即驾驶舱要自动拉最新数据，而非每次手动粘贴。
- 经 AskUserQuestion 确认为：**只读同步 + 本地桥接**（最稳、数据不出本机）。
- 根因：WPS/腾讯表均为「登录可见」私有表，纯静态网页读不到（v1.4.1 已实测腾讯表 401 + 浏览器 CORS）。方案：在你本机跑 Node 服务用一次性授权去拉数据存本地，网页自动读。
- 交付 **bridge/** 目录（新增）：`server.js`(纯 Node 零依赖：托管网页+`/api/data`+`/api/sync`+`/api/upload`同源上传+监听`drop/`目录自动读CSV)、`parse.js`(与前端一致的任务/会议室解析)、`fetchers.js`(WPS官方OpenAPI/公开链接 + 腾讯公开链接 best-effort，失败回退)、`config.example.json`/`config.json`(含腾讯预填链接+空token，gitignore)、`.gitignore`(屏蔽 config.json/data/drop)、`README.md`。
- 三种喂数据方式（按稳当排序）：① **网页粘贴框点"上传到本地服务"**(推荐，同源无跨域)；② **丢 CSV 到 drop/wps 或 drop/tencent**(常开即自动读)；③ 填公开链接让服务端抓(最佳努力，私有会失败回退)。
- 进阶自动（可选非必需）：WPS 用官方 OpenAPI 填 fileToken+access_token；或两表都设「公开可读」填 publicLink（央企慎用以免数据暴露公网）。
- 驾驶舱 UI v1.5.0 改动：顶部"自动同步"状态条(显示最近更新时间+各来源模式/错误)；任务/会议室粘贴框新增"上传到本地服务"按钮；"同步读取"改走本地服务端(绕 CORS)；启动即拉 `/api/data` 覆盖示例，每 60 秒轮询。
- 经单壳端到端测试：`/api/data`、`/api/upload`(TSV+CSV)、`/api/sync`(含 drop 回退)、初始空状态均通过。
- 已提交+打tag v1.5.0+push GitHub(六 tag 全在)；origin 分支为 master（非 main），远程已加 PAT。
- 使用提示（给用户）：在 bridge 目录 `node server.js`，浏览器开 `http://localhost:8787`；关窗即停。不是云端服务，只在用户本机跑。
- **安全重申**：对话中明文 GitHub token(ghp_...) 与旧飞书 app_secret 仍在，务必用后重置/吊销（bridge 不依赖这些旧凭证）。

任务数据（WPS 在线表格）：在 WPS 表里全选 → 复制 → 粘贴到下方文本框 → 点「生成驾驶舱」仅本机预览；点「上传到本地服务」让驾驶舱自动刷新。也可上传 CSV 文件。

会议室数据（腾讯在线表格）：在腾讯表格里选中预约区域（含表头）→ 复制 → 粘贴 → 点「生成会议室」预览，或「上传到本地服务」。若腾讯表已设为公开可读，也可填链接后点「同步读取」。

签证情况（WPS 在线表格 · 签证 sheet）：在 WPS 表的「签证」sheet 中全选 → 复制 → 粘贴到下方文本框 → 点「上传到本地服务」，驾驶舱自动刷新。也可上传 CSV 文件。

车辆情况（WPS 在线表格 · 车辆信息 / 车辆排期 两个 sheet）：在 WPS 表对应 sheet 全选 → 复制 → 粘贴到下方文本框 → 点「上传到本地服务」，驾驶舱自动刷新。也可上传 CSV 文件。

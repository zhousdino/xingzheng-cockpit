行政部驾驶舱 · WPS 在线表格搭建清单 v1.1.0

后台：WPS 在线表格（在线 Excel 型）｜ 版本：v1.1.0（从 v1.0.0 飞书方案迁移）｜ 约 12 人共用
⚠️ 与飞书的不同：WPS 在线表格是"在线 Excel"，没有看板视图、没有人员字段。所以做法改为：下拉选大类/状态、数据条显示进度、筛选看每人、插入图表做总览。功能一样齐全，只是界面没飞书炫。

一、建表与共享

  1. 打开 WPS 网页版（kdocs.cn） → 新建 → 在线表格 → 命名为 「行政部驾驶舱」。
  2. 右上角 「分享」 → 生成链接 → 权限选 「可编辑」 → 复制链接发给部门 12 位同事。大家都能填、能看。
权限说明：WPS 在线表只能整表"可看/可编辑"，做不到飞书那种"领导只看总览、成员只看自己"。这点先接受，靠大家自觉填自己那行即可。

二、列（字段）清单——第 1 行写表头，照着填

列表头名怎么填说明
A任务名称直接打字—
B所属大类下拉选见下方"下拉设置"
C子项备注打字具体子任务
D负责人打字写人名WPS 无"人员"字段，直接写名字
E协同人打字，多人用、隔开如"张三、李四"
F状态下拉选未开始/进行中/已完成/已暂停/已逾期
G进度%填数字 0–100配合数据条显示进度
H开始日期日期—
I截止日期日期逾期判定 + 排序靠它
J优先级下拉选高/中/低
K堵点说明打字卡在哪、需谁协调
L是否逾期公式见下方"公式"
M更新日期打字 / 公式填最后修改日，便于看新鲜度

三、下拉设置（让大类/状态/优先级只能选，不乱填）

  1. 选中要设置的列（如 B 列整列，或 B2:B1000）。
  2. 顶部菜单 「数据」 → 「数据验证」（有的版本叫"有效性"）。
  3. 允许 → 选 「序列」。
  4. 来源里输入选项，用英文逗号隔开，例如所属大类：
    会务接待,车辆管理,后勤管理,物资采购,行政办公,人力资源,其他
  5. 确定。以后这列点一下就出下拉，不会填错。
  6. 状态列同理：未开始,进行中,已完成,已暂停,已逾期；优先级：高,中,低。

四、进度条 + 逾期标红（条件格式）

  1. 进度数据条：选中 G 列（进度%）→ 顶部 「开始」 → 「条件格式」 → 「数据条」 → 选个颜色。数字立刻变成可视进度条。
  2. 逾期标红：选中整张数据区 → 「条件格式」 → 「新建规则」 → 规则类型选"使用公式" → 输入 =$L2="逾期" → 格式设为红色填充 → 确定。逾期行自动变红。
  3. 状态上色（可选）：再建几条规则，=$F2="已完成" 绿色、=$F2="进行中" 黄色，一眼分清。

五、是否逾期公式（L2 单元格粘贴，往下拖）

=IF(AND(F2<>"已完成", I2<>"", TODAY()>I2), "逾期", "正常")
含义：状态不是"已完成"、且有截止日期、今天已超过截止日 → 显示"逾期"，否则"正常"。把 L2 写好，鼠标拖右下角填充柄往下拉，整列都生效。
更新日期 M 列：可手动填，或简单用 =TODAY()（但每次打开会变，建议手动填"最后更新日"更准）。

六、看清"每人进展"——筛选

  1. 选中数据区域（含表头）→ 顶部 「数据」 → 「筛选」。每列表头出现小三角。
  2. 点 D 列（负责人） 小三角 → 勾选某个人 → 表格只显示他负责的活。看 G 列进度条即知进展。
  3. 点 F 列（状态） 小三角 → 取消"已完成" → 只看还没干完的，适合周会过进度。

七、总览仪表盘——单独建一个"仪表盘"工作表

  1. 底部点 「+」 新建一个工作表，命名 「仪表盘」。
  2. 统计卡：在仪表盘写几个 COUNTIF 公式（假设数据在"任务总表"）：
    · 总任务数：=COUNTA(任务总表!A2:A1000)
    · 已完成：=COUNTIF(任务总表!F2:F1000,"已完成")
    · 进行中：=COUNTIF(任务总表!F2:F1000,"进行中")
    · 逾期：=COUNTIF(任务总表!L2:L1000,"逾期")
  3. 完成率：=已完成/总任务数，单元格设为百分比格式。
  4. 图表：选中统计区 → 顶部 「插入」 → 「图表」 → 状态分布用饼图、各大类任务数用柱状图。
数据表一更新，仪表盘公式和图表自动跟着变，不用手动重算。
✅ 以上点完，WPS 版驾驶舱就搭好了：大家填"任务总表"，领导看"仪表盘"，要盯某人就筛选 D 列。字段/大类/人员后期都能手动增减——加大类就改 B 列下拉的来源，加人直接在 D 列写新名字。

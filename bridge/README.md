# 行政部驾驶舱 · 本地桥接服务（v1.5.0 配套）

> 解决一个现实问题：**WPS 和腾讯的表格都是"要登录才看得到的私有表"，纯网页读不到。**
> 本服务跑在你自己电脑上，用你的一次性授权去拉最新数据，存成本地文件，驾驶舱网页自动读——**数据不出本机、不暴露到公网**。

---

## 一、它能做什么

- 托管驾驶舱网页（`行政部驾驶舱_UI_v1.5.0.html`），浏览器访问 `http://localhost:8787` 即可看。
- 自动同步 **WPS 在线表格（任务）** 和 **腾讯在线表格（会议室）** 的最新数据。
- 网页每 60 秒自动刷新，顶部"自动同步"条显示最近更新时间与来源状态。
- 提供三种喂数据方式，**按稳当程度排序**：

| 方式 | 怎么用 | 稳不稳 | 要登录吗 |
|------|--------|--------|----------|
| ① 浏览器"上传到本地服务" | 在驾驶舱粘贴框粘贴 → 点"上传到本地服务" | ✅ 最稳（同源、无跨域） | 不用，你已手动粘了 |
| ② 丢 CSV 文件 | 把表格导出/复制成 CSV，丢进 `drop/wps/` 或 `drop/tencent/` | ✅ 很稳，常开即自动读 | 不用 |
| ③ 填公开链接自动抓 | 把表设为「获得链接的人可阅读（公开）」填进 `config.json` | ⚠️ 最佳努力，私有的抓不到 | 不用（公开） |

> 推荐日常用 **①**：在 WPS/腾讯表复制整张（含表头）→ 粘到驾驶舱粘贴框 → 点"上传到本地服务"。驾驶舱立刻更新，且 60 秒后还会自动再确认一次。

---

## 二、怎么启动（两步）

1. **安装 Node**：若已装可跳过。本项目用的是内置 Node（见下方命令），或你本机 `node` 也行（v18+）。
2. **启动服务**：在 `bridge/` 目录运行
   ```bash
   node server.js
   ```
   看到 `行政部驾驶舱桥接服务已启动：http://localhost:8787` 即成功。
3. **打开驾驶舱**：浏览器访问 `http://localhost:8787`（或 `http://localhost:8787/cockpit.html`）。

> 关闭窗口 = 停止服务；想持续同步就让它一直开着（可最小化）。**它不是云端服务，只在你这台电脑上跑。**

## 三、想"全自动免粘贴"？两种进阶配置（可选）

### 方案 A：WPS 用官方 OpenAPI（最规范，推荐想自动的人）
WPS 有官方开放平台 `developer.kdocs.cn`。需要：
1. 在 WPS 开放平台建应用，拿到 `access_token`；
2. 把表格的 `file_token`（从 `kdocs.cn/l/<token>` 取 `<token>`）和 `access_token` 填进 `bridge/config.json` 的 `wps` 段；
3. 重启服务，即可每 60 秒自动拉最新任务数据。

### 方案 B：把两张表设为「公开可读」
- 在 WPS/腾讯里把表分享设为 **"获得链接的人可阅读"**，把链接填进 `config.json` 的 `wps.publicLink` / `tencent.publicLink`；
- ⚠️ **央企场景慎用**：部门任务数据会暴露到公网。腾讯表若仍是私有，"公开链接自动抓"也会失败，此时退回方式①/②。

> 不配置也完全能用——默认就是方式①/②（手动上传或丢文件），零门槛、零风险。

## 四、目录结构

```
bridge/
├─ server.js            # 桥接服务（托管网页 + 接口 + 自动同步）
├─ parse.js             # 表格文本解析（与前端一致）
├─ fetchers.js          # WPS / 腾讯 抓取逻辑（best-effort）
├─ config.json          # 你的私有配置（链接 / token）——已 gitignore，勿提交
├─ config.example.json  # 配置模板
├─ drop/
│  ├─ wps/              # 把任务 CSV 丢这里（子集）
│  └─ tencent/          # 把会议室 CSV 丢这里（子集）
└─ data/                # 服务自动生成的最新数据 JSON（gitignore）
```

## 五、接口一览（给想二次开发的人）

- `GET  /api/data`    —— 返回最新 `{tasks, rooms, updatedAt, sources}`
- `POST /api/sync`    —— 触发重新抓取（body 可带 `{wpsLink, tencentLink}` 临时覆盖链接）
- `POST /api/upload`  —— 浏览器同源上传（body `{type:'tasks'|'rooms', text}`）
- `GET  /api/status`  —— 各来源最近同步状态 / 错误

## 六、注意

- **这不是云端服务**，只在你本机跑；要让别人也实时看，需在他电脑也跑一份，或后续部署到内网服务器。
- `config.json` 含你的凭据，**不要提交到 GitHub / 发给别人**。仓库已用 `.gitignore` 屏蔽它和 `data/`、`drop/`。
- 私密数据（工资/身份证/处分）仍不进表，遵守原项目约束。
